# St. Pete Home Check

A password-protected screening map for St. Petersburg, Gulfport, Lealman, Pinellas Park and Kenneth City, FL. Enter an address to see elevation, FEMA flood zone, city stormwater flooding, 2025 tree canopy, road noise and bike access.

The page is encrypted with [StatiCrypt](https://github.com/robinmoisson/staticrypt); its contents can't be read without the password.

Provided as-is for informal screening only. Not an official flood determination or professional advice.
